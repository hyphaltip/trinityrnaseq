trinityrnaseq
=============

Trinity RNA-Seq de novo transcriptome assembly see the Trinity [wiki](https://github.com/trinityrnaseq/trinityrnaseq/wiki)

> **This is an unofficial fork** ([hyphaltip/trinityrnaseq](https://github.com/hyphaltip/trinityrnaseq), version `2.16.1_rust`) maintained by [Jason Stajich](https://github.com/hyphaltip), tracking the official [trinityrnaseq/trinityrnaseq](https://github.com/trinityrnaseq/trinityrnaseq) repository. It adds experimental performance optimizations (see below) not present upstream. Please file issues/bugs specific to this fork's Rust optimizations against this repository, not upstream; for anything else, use the official repo above.

## Contributing

We encourage you to contribute to Trinity! Please check out the [Contributing](https://github.com/trinityrnaseq/trinityrnaseq/wiki/Contributing) for the guidelines.

## 2026 edits

Performance profiling and improvements to convert some perl components to Rust with assistance of AI tools. See `Changelog.txt` for details of what changed in `2.16.1_rust` versus the upstream release it was branched from.
